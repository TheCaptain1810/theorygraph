# Eight-Week Roadmap

Assumption: roughly 8–12 hours/week alongside a job. This is a plan, not a guarantee.

## Week 1 — Research and prototype
- Interview 8–12 cinephiles.
- Inspect competitors hands-on.
- Prototype film page, interpretation page, evidence editor, and counter-reading flow.
- Decide the smallest testable workflow.

**Exit criteria:** users understand the core distinction between observation and interpretation.

## Week 2 — Foundation
- Set up app, database, migrations, auth, environment variables, deployment.
- Add health check and basic error handling.
- Establish linting, formatting, and tests.

**Exit criteria:** deployed skeleton with working authentication.

## Week 3 — Film and interpretation pages
- Integrate permitted film metadata.
- Implement film search and details.
- Create and display interpretations.

**Exit criteria:** authenticated user can publish a structured interpretation.

## Week 4 — Evidence and counter-readings
- Implement scene references and evidence types.
- Implement counter-readings with independent evidence.
- Add server-side permissions and validation.

**Exit criteria:** a complete claim/evidence/counter-reading workflow.

## Week 5 — Discovery and spoilers
- Add tags, search, filters, public URLs, and spoiler gates.
- Improve empty/loading/error states.

**Exit criteria:** a visitor can discover and understand a useful discussion.

## Week 6 — Quality and moderation
- Add report flow and a basic moderator workflow.
- Test authorization and spoiler behaviour.
- Review accessibility, mobile UI, and data-source terms.

**Exit criteria:** usable beta with basic abuse handling.

## Week 7 — Pilot
- Invite 15–30 relevant users.
- Observe usage and collect qualitative feedback.
- Measure meaningful contributions and return visits.

**Exit criteria:** evidence about whether the core loop is useful.

## Week 8 — Iterate and decide
- Fix the largest usability barrier.
- Improve onboarding and seed content.
- Decide whether to continue, pivot, or stop.

**Exit criteria:** a decision based on observed behaviour, not compliments.

## Defer
AI theory generation, automatic frame analysis, recommendations, native apps, realtime editing, subscriptions, and elaborate graph visualisation.
